# Zigriy — лендинг пальмових свічок

Односторінковий магазин для [@zigriy.candles](https://www.instagram.com/zigriy.candles/) за структурою candles.lukaaroma.com.ua:
таймер акції, набори зі знижкою, каталог ароматів з кошиком, відгуки і FAQ.
Замовлення приймаємо лише в Instagram Direct: кнопка «Замовити в Direct» копіює список обраних ароматів
і відкриває Instagram, покупцю лишається вставити його в повідомлення.

Без збірки й залежностей: статичний HTML/CSS/JS.

## Структура

```
index.html               сторінка
assets/css/style.css     стилі (кольори бренду — у :root)
assets/js/config.js      ⚙️ ціни, набори, аромати, пікселі — редагувати тут
assets/js/app.js         кошик, модалка, таймер, відгуки
assets/img/scents/       фото ароматів 800×800 (<id>.webp)
assets/img/reviews/      відгуки (сторіс 9:16)
assets/video/hero.mp4    відео в першому екрані
api/order.js             стара форма замовлення → Telegram (сайт її зараз не викликає)
vercel.json              кешування і заголовки
```

## Деплой на Vercel

1. Залийте папку в GitHub-репозиторій → у Vercel **Add New → Project → Import**.
   Framework Preset: **Other**, Build Command і Output Directory залиште порожніми.
   Або з терміналу: `npx vercel` (потрібен Node.js 18+).

Змінні середовища не потрібні: замовлення йдуть у Direct, а не через сервер.

Після підключення домену замініть в `index.html` `og:image` на повну адресу (`https://ваш-домен/assets/img/og.jpg`) —
так прев’ю посилання в месенджерах і Facebook буде з картинкою.

## Як змінити ціни й асортимент

Усе в `assets/js/config.js`:

- `SINGLE_PRICE` — ціна однієї свічки;
- `SETS` — набори `{ qty, price }`, від більшого до меншого;
- `FREE_SHIPPING_FROM` — поріг безкоштовної доставки;
- `COUNTDOWN: false` — прибрати таймер «ціни діють лише сьогодні»;
- `META_PIXEL_ID`, `TIKTOK_PIXEL_ID` — вставте ID, і пікселі ввімкнуться самі;
- `SCENTS` — аромати. Новий аромат: додайте рядок і фото `assets/img/scents/<id>.webp` (квадрат 800×800).
  `img2` — друге фото, яке з’являється при наведенні.

## Що взято з Instagram, а що треба підтвердити

З профілю @zigriy.candles: лого й кольори, 8 ароматів (хайлайт «Асортимент» + осіння колекція із закріпленого поста),
ціна **450 грн / 200 мл**, фото, відео, тексти про пальмовий віск і дерев’яний ґніт, сторіс-відгуки.

Погоджено окремо: набори 3 / 6 / 12 шт за 1 250 / 2 350 / 4 300 грн, безкоштовна доставка від 1 200 грн.

**Перевірте перед запуском:** короткі описи ароматів (крім «Пряного апельсина» — він з вашого поста) написані за назвами.

## Локальний запуск

- Будь-який статичний сервер, напр. `python3 -m http.server`.
- Або без сервера: `zigriy-standalone.html` — увесь сайт в одному файлі, відкривається подвійним кліком.
  Після змін у сторінці, стилях чи `config.js` перезберіть його: `python3 build_standalone.py`.
